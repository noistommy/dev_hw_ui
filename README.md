
# hw-ui-component(HWUI)

![hw-ui-screenshot](https://github.com/user-attachments/assets/85a81282-80e2-4db9-8641-0aad2a738a96)

`hw-ui-component` 는 vue 프레임 워크(`vue`)에 적용 가능한 UI 컴포넌트 라이브러리입니다. 재사용 가능한 UI 요소들을 사용해 빠르게 페이지 구현 및 화면 기능을 구현 할 수 있습니다.

- Story

이 프로젝트는 **외부 라이브러리 사용으로 인한 디자인 커스터마이징의 한계**와 **성능 저하 문제**를 해결하고자 시작되었습니다. 기존에 사용하던 외부 UI 라이브러리를 **교체**하였으며, 이후 요구사항에 맞춰 **여러 컴포넌트를 새롭게 설계 및 추가**하였습니다.

- Update

vue 버전에 맞춰 업데이트 할 필요가 있으며 현재 각 컴포넌트에 과도한 옵션 사용으로 사용의 어려움이 있다고 생각합니다. 필수/선택 옵션에 대한 정리가 필요합니다. 
(이후 nt-ui-component를 통해 업데이트)
